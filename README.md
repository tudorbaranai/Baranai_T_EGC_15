# EGC – Elemente de Grafică pe Calculator (2026-2027)

Laboratory homework, Tudor Baranai, group 3132a, USV FIESC.

C# / .NET 8 / OpenTK. Each homework lives on its own branch and contains only the project folder:

| Branch   | Laboratory | Project folder |
|----------|------------|----------------|
| `tema04` | Lab #04 – transformations, camera, keyboard and mouse | `EgcLab04/` |
| `tema05` | Lab #05 – procedural mesh, FPS camera, FOV, orbit camera | `EgcLab05/` |

Open the `.csproj` from the project folder in Visual Studio 2022 and press F5.
